First Install some Programs IP FIX - NOT MUCH TO INSTALL.

Fix IP problem for. Cant find screen problem. Look for ip adress in windows terminal / PowerShell: ipconfig

OPEN POWER SHELL AND TYPE: ipconfig

SAVE IP ADRESS FOR LATER USE: 172.21.224.1 - LOOK DOWN =)

NOTE - Importent to look for ip. Last lines are IP-numbers for WSL in Powershell

GO BACK TO FEDORA 45 Terminal AND COPY AND PASTE THIS IN TERMINAL.

sudo systemctl unmask systemd-resolved.service
sudo systemctl enable systemd-resolved.service

sudo ls -l /etc/resolv.conf
sudo mv /etc/resolv.conf /tmp/resolv.conf.bak
sudo nano /etc/resolv.conf

nameserver 172.21.224.1  <-- put your ip here and add nameserver.

sudo chattr +i /etc/resolv.conf
sudo systemctl restart systemd-resolved
sudo cat /etc/resolv.conf

NOTE - Run this in terminal.

sudo sudo systemctl daemon-reload
