Fix IP problem X410. Cant find screen problems. Look ip adress in windows terminal / PowerShell: ipconfig

NOTE: open Powershell and type: ipconfig - Last lines is WSL ip.

GO BACK TO FEDORA 44 AND COPY AND PASTE THIS.....

SAVE IP FOR FEDORA 44 FROM POWERSHELL HERE: 172.30.16.1

sudo ls -l /etc/resolv.conf
sudo mv /etc/resolv.conf /tmp/resolv.conf.bak
sudo nano /etc/resolv.conf

nameserver 172.30.16.1  <-- put your ip here from POWERSHELL and add nameserver.

sudo chattr +i /etc/resolv.conf
sudo systemctl restart systemd-resolved
sudo cat /etc/resolv.conf

DONE - alot of problem fixed for FEDORA 44 and KDE 6
